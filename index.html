ACCESSIBILITY FAQ

Common questions

What does this accessibility checker test?

It checks practical HTML signals including document language, page title, heading structure, image alternative text, link names, form labels, landmarks, buttons, tables, and basic color-contrast hints.

Does a score of 100 mean a website is fully accessible?

No. Automated checks can identify many common problems but cannot replace manual keyboard testing, screen-reader testing, usability testing, or a complete WCAG conformance assessment.

Can I audit any public website URL?

Only when the target page permits browser access. Cross-origin security rules can prevent a browser-only tool from reading arbitrary pages. Pasting the HTML is the reliable alternative.
